# Learn Python End-to-End (learningpython)

This repository is a step-by-step set of small Python programs meant to help you learn **Python end-to-end**—from basic syntax to control flow and core data structures.

> Note: The scripts in `learningpython/` are mostly **examples** (many run immediately and use `input()`), so reading them and running them one-by-one is the best way to learn.

---

## What’s inside

### 1) Starter / Basics
- **`my_python.py`**: printing, variables, `input()`, type conversion, and basic built-ins (`max`, `min`).
- **`string_example.py`**: string slicing and string formatting with f-strings.

### 2) Data Structures
- **`list.py`**: list creation + common operations (`append`, `insert`, `extend`, `remove`, `pop`), plus `min`, `max`, `sum`, `len`.
- **`tuple.py`**: tuple usage + immutability concept, indexing, and string methods.
- **`dictionary.py`**: dictionary fundamentals (key/value access, length, updating entries).
- **`sets.py`**: set behavior, membership tests, union/intersection/xor/differences, and `frozenset`.

### 3) Control Flow
- **`condition.py`**: `if`, `if-else`, `if-elif-else`, nested `if`, ternary operator.
- **`for_loop.py`**: `for` loops over lists/strings/tuples/dicts, `range()`, and iterating dictionary items.
- **`continue_break.py`**: `continue` and `break` in loops.

### 4) Small Practice/Formula Programs
- **`simple_interest.py`**: compute simple interest.
- **`compound_interest.py`**: compute compound interest.
- **`area_of_triangle.py`**: compute triangle area using the semi-perimeter formula.
- **`arithmetic_with_loop.py`**: iterate over a list of scores and compute totals/avg/min/max plus even/odd aggregations and powers.

---

## Recommended learning path (end-to-end)

1. **Run & understand**: `my_python.py`
2. **Strings**: `string_example.py`
3. **Lists**: `list.py`
4. **Tuples**: `tuple.py`
5. **Dictionaries**: `dictionary.py`
6. **Sets**: `sets.py`
7. **Conditions**: `condition.py`
8. **Loops (for/range/dicts)**: `for_loop.py`
9. **Loop control**: `continue_break.py`
10. **Build confidence with formulas**:
    - `simple_interest.py`
    - `compound_interest.py`
    - `area_of_triangle.py`
11. **Mixed practice (loops + logic)**: `arithmetic_with_loop.py`

## How to run (typical)

From the project root (`d:/learning_python`):

```bash
python learningpython/<script_name>.py
```

### Example
```bash
python learningpython/my_python.py
```

---

## Notes / Best practices while learning

- Many scripts call `input()`—run them and observe the outputs.
- Read the code comments/docstrings first, then run.
- If a script mixes multiple examples, focus on one concept at a time (e.g., one kind of `if` or one list operation).
- Consider copying the code into your own scratch files and modifying variable names and inputs.
